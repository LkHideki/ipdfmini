# Código de conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate as pessoas com respeito, critique ideias e não pessoas, e não tolere assédio. Comportamento inaceitável pode levar à remoção de comentários, commits e issues e ao bloqueio no repositório.

Para relatar um problema de conduta, fale com o mantenedor pelo perfil [@LkHideki](https://github.com/LkHideki) no GitHub. Os relatos são tratados com sigilo.
