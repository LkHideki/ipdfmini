# Segurança

O iPDFmini abre PDFs de origem desconhecida. Para limitar o estrago de um arquivo malicioso, a análise e a conversão rodam num processo filho separado do app.

## Como relatar uma vulnerabilidade

Use o relato privado do GitHub: aba **Security** → **Report a vulnerability**. Não abra issue pública.

Descreva o que acontece e, se possível, inclua um arquivo que reproduza o problema. A resposta inicial costuma sair em até uma semana. Este é um projeto mantido por uma pessoa, sem programa de recompensa.

## Versões cobertas

Só a versão mais recente da branch `main` recebe correções.
